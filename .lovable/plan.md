
## Что делаем

Подключаем **Lovable Cloud** (база данных + авторизация + серверные функции) и переносим сайт с Shopify на собственный бэкенд с оплатой через Finik API.

## Структура базы данных

- **profiles** — имя, телефон, привязка к auth-пользователю (создаётся автоматически при регистрации)
- **user_roles** — роли (`admin`, `customer`) в отдельной таблице (для безопасности)
- **categories** — категории продуктов (мука, масла, молочное и т.д.)
- **products** — товары: название, описание, цена, фото, категория, остаток, активен/нет
- **addresses** — адреса доставки пользователя (несколько адресов на клиента)
- **orders** — заказы: пользователь, адрес, сумма, способ доставки, статус (`pending` → `paid` → `preparing` → `delivering` → `delivered` / `cancelled`), статус оплаты, ссылка на платёж Finik
- **order_items** — позиции заказа с зафиксированной ценой на момент покупки
- **delivery_zones** — зоны доставки и их стоимость

RLS: клиент видит только свои заказы/адреса; админ видит и меняет всё; каталог читается всеми.

## Авторизация

- Email + пароль (по умолчанию) и Google — включаем через Lovable Cloud
- Поле телефона в профиле (нужно для доставки)
- Роль `admin` назначается вручную первому пользователю через SQL

## Оплата Finik

1. Клиент оформляет заказ → создаётся запись `orders` со статусом `pending`
2. Серверная функция вызывает Finik API (создание счёта / инвойса), сохраняет `finik_payment_id`
3. Клиент видит QR-код / кнопку оплаты Finik
4. Webhook от Finik (`/api/public/webhooks/finik`) с проверкой подписи → меняет статус заказа на `paid`
5. Админ видит оплаченный заказ и обрабатывает его

## Витрина (клиентская часть)

- Главная и карточка товара переключаются с Shopify Storefront на запросы к Lovable Cloud
- Корзина остаётся на клиенте (Zustand), но при оформлении заказа отправляется на сервер
- Новые страницы:
  - `/auth` — вход и регистрация
  - `/checkout` — оформление заказа (адрес + способ оплаты Finik)
  - `/orders` — история заказов клиента
  - `/orders/$id` — детали заказа + оплата, если не оплачен
  - `/admin` (за ролью admin): товары, категории, заказы, зоны доставки

## Технические детали

- Все серверные вызовы через `createServerFn` c `requireSupabaseAuth`, кроме публичного webhook Finik
- Каталог грузится публично через `TO anon` SELECT-политики
- Изображения товаров — Lovable Cloud Storage, бакет `product-images` (публичный)
- Shopify-код (`src/lib/shopify.ts`, `product.$handle.tsx`) заменяем; корзина/чекаут-логику Shopify удаляем
